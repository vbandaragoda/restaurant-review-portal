# Restaurant Review Portal

A restaurant review portal covering restaurants in Colombo, Kandy and Galle.

## Tech Stack

- Frontend: ReactJS
- Backend: Spring Boot
- Database: PostgreSQL
- Version Control: Git

## Main Features

- Search restaurants and menu items
- Browse restaurants by cuisine category
- Filter by vegetarian, vegan, halal and spice level
- Filter restaurants by price band
- Support English, Sinhala and Tamil content
- Restaurant and menu item ratings
- Customer reviews and comments
- Restaurant responses to reviews
- Moderator approval of user-generated content
- Admin management of restaurants, menus, prices and images
